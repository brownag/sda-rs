# Task 1.3.1 Micro-plan — SDA Query Request Routes

## Goal

Implement both SDA tabular POST routes with JSON and URL-encoded requests, case-insensitive `query`/`format` fields, safe T-SQL transpilation, configured SQLite execution, SDA serialization, and structured errors.

## Preconditions and scope

- Dependencies 1.2.1, 1.2.2, and 1.3.2 are complete. `planning/STATE_1.md` records 1.3.2 serializer registration and successful wave-boundary verification (`cargo test`: 13 passed; `cargo fmt --check`: passed).
- Authorized implementation files only:
  - `src/routes.rs`, `src/request.rs`
  - `src/lib.rs` for app state and route wiring; preserve serializer registration.
  - `src/main.rs` to pass configured `Config` into the app.
  - `src/executor/mod.rs`, `src/executor/sqlite.rs` for configured per-request SQLite-path execution while preserving `spawn_blocking`.
- Do not edit config internals, transpiler, serializer internals, spatial initialization, planning source documents, dependencies, or create files.
- Preserve existing untracked `target/`; no remote actions.

## Implementation steps

1. Inspect current APIs and pass the configured backend path from `main.rs` through `lib.rs` app state to route handlers.
2. Extend the executor API to accept the configured SQLite path and open a fresh request-local connection to that path inside the existing `spawn_blocking` boundary. Preserve sequential statement/session behavior.
3. Implement request parsing in `src/request.rs` for JSON and `application/x-www-form-urlencoded`; normalize field names case-insensitively and return structured errors for malformed input or missing query.
4. Implement both POST handlers in `src/routes.rs`: transpile and validate SQL, execute using the configured SQLite path, serialize using the requested registered serializer format, and return structured errors for request, transpilation, and execution failures.
5. For `FORMAT=~`, return the submitted SQL as `text/plain` without transpilation or execution; macro expansion remains deferred.
6. Wire app state and both routes in `src/lib.rs`, preserving middleware and serializer module registration.
7. Add in-process router tests without TCP ports. Cover both endpoints with both encodings, mixed-case keys, missing query, unsafe query, query echo without execution, and execution against a configured temporary SQLite file fixture. Constant-only cases may use `:memory:`.
