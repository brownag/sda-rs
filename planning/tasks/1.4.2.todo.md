## Task 1.5.1 interface contract
`execute_query_blocking` initializes the connection and passes `&SpatialCapability` plus the original query to its preparation callback before SQLite execution. The capability provides stable accessors for spatial availability, optional discovered GeoPackage table/geometry-column/SRS metadata, effective override, and structured `require_spatial` failure. Task 1.5.1 can consume this callback seam during AOI/UDF rewriting without changing executor initialization. Missing GeoPackage metadata remains distinct from unavailable spatial functions.
