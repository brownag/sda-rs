Provide a per-request spatial capability/metadata value from executor initialization, with stable accessors for: spatial functions available/unavailable, optional discovered GeoPackage table/geometry-column/SRS metadata, and a structured `require_spatial` failure. Keep this API independent of SQL transpilation; 1.5.1 can consume it when implementing AOI/UDF rewrites and error handling.
